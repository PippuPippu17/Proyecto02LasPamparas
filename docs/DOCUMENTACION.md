# Documentación del Proyecto

## Introducción
Este proyecto trata sobre el modelado y programación de un sistema de lámparas.

## Objetivo
El objetivo de este proyecto es desarrollar un sistema que modele el comportamiento de diferentes tipos de lámparas.

## Conceptos Clave
- **Lámpara**: Dispositivo de iluminación
- **Estado**: Encendida/Apagada
- **Intensidad**: Nivel de brillo
- **Tipo**: Diferentes tipos de lámparas (LED, incandescente, fluorescente, etc.)
