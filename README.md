# Proyecto02LasPamparas
Proyecto 2 Modelado Y Programación

## Descripción
Este es el Proyecto 2 sobre modelado y programación con el tema de Las Lámparas (The Lamps).

## Estructura del Proyecto
```
Proyecto02LasPamparas/
├── README.md          # Este archivo
├── src/              # Código fuente
├── docs/             # Documentación
└── examples/         # Ejemplos de uso
```

## Cómo Empezar
1. Clone este repositorio
2. Explore la carpeta `src/` para el código fuente
3. Revise la carpeta `examples/` para ver ejemplos

## Contribuciones
Este es un proyecto académico para el curso de Modelado y Programación.

## Ayuda
Si necesita ayuda con el proyecto, por favor consulte la documentación en la carpeta `docs/` o contacte al profesor del curso.
